# ブラウザで遊べるオセロ

**[▶ オセロをプレイする](https://ldkybe.github.io/pyxel-othello-play/)**

PC・スマホのブラウザで遊べます。インストールやログインは不要です。

## 遊び方

1. 上のリンクを開き、開始画面をクリックまたはタップします。
2. 人間対CPU・ふたり対戦を選びます。CPU対戦では先手・後手も選べます。
3. 「開始」を選んで決定すると、対局が始まります。
4. カーソルを置けるマスへ動かして決定します。

## 操作方法

| 操作 | PCのキーボード | スマホの画面ボタン |
|---|---|---|
| 移動・項目の選択 | 矢印キー | 十字キー |
| 決定・石を置く | Z | A |
| メニュー・取消 | X / Escape | B |

Enter・Spaceは決定に使いません。スマホは盤面の直接タップではなく、画面の十字キーとA/Bボタンで操作します。

メニューから効果音のオン・オフやリセットができます。CPUの思考中もメニューを開けます。対局が終わったら、再戦を選んで続けて遊べます。
